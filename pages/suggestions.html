Suggestions for improving the site

This section lists concrete suggestions for improving the Baymich2 dashboard so someone can review them and choose the best path before implementing any changes. None of these are live yet.

1
Add an interactive map

Plot each restaurant on a Leaflet or Google Map using coordinates from its official MICHELIN page, filterable by star level and cluster.

2
Fill in verified pricing

Visit each restaurant's official website to confirm tasting-menu / à la carte prices and replace the "(est.)" estimates with exact, sourced totals for 2 adults (tax/tip excluded).

3
Add social-media links (IG / YouTube / TikTok)

Every row currently shows "n/a" for social. Search each restaurant's official site for linked Instagram, YouTube, and TikTok accounts and add them.

4
Add Bib Gourmand & "listed only" restaurants

This version focuses on the 39 starred entries. Add the full 2026 Bib Gourmand list and the broader "Recommended"/listed selection so the guide is complete.

5
Confirm missing hours

Several restaurants show "Hours unverified". Pull hours from each official site and note exceptions (holidays, seasonal closures, private events).

6
Verify current operating status

The 2025→2026 change dropped some one-star restaurants (e.g., State Bird Provisions, Mister Jiu's, Osito). Re-check each entry is still open and starred before publishing.

7
Add distances / drive times between hotels and clusters

Replace the qualitative "cluster density" with approximate miles/minutes from each hotel to its nearby starred restaurants.

8
Enable filtering & sorting

Add client-side filters (star level, region, price, cuisine) and sorting (by stars, price, name) to the restaurants table.

These suggestions are proposals only. Review the open Questions page before deciding which to implement.
