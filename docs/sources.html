Sources & Method

Primary sources (official)

  • MICHELIN Guide — Every MICHELIN-Starred Restaurant in California for 2026 (published 24 June 2026). Used for star status and the 83-restaurant count.
  • Official Michelin restaurant pages (guide.michelin.com/us/en/…). One link per row in the Michelin table. Used for address, phone, restaurant website, price tier, and listed hours.

Secondary sources (cross-check only, not used as values)

  • Eater SF — 2026 Michelin Star Winners of the Bay Area. Used to find conflicts (see Flagged).

Method

  1. Read the official article and copy star lists exactly.
  2. Open each official restaurant page and copy address, phone, website, price tier, and listed hours.
  3. If a value is missing from the official page, leave it blank and flag it. Nothing is inferred.
  4. Compare against secondary sources and flag any conflict.

Data files

  • data/michelin_starred_bay_area.json — table data.
  • data/review.json — flags, questions, suggestions.
  • COORDINATION.md — shared task board and session log.
Every value links to an official source. Blank or “Not verified” means it could not be confirmed from an official source. Data as of 2026-11-24. Built from data/ by scripts/build_site.py.
