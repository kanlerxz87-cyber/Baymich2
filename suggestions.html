Suggestions

Options to review and choose from before implementing the next phase. These are suggestions, not commitments.

1. Publish scope (choose one)

  • Option A — Starred only (recommended to ship first): Publish the 29 starred restaurants with full verification. They are complete, sourced, and high value. Defer listed-only (116) and hotels until verified.
  • Option B — Starred + listed-only placeholder: Publish starred plus a listed-only index page showing names + official MICHELIN links, clearly marked unverified/blank. Good for completeness but lower data quality.
  • Option C — Full: Publish starred + listed-only + hotels. Requires fetching 90+ more detail pages and hotel verification; not recommended before a first release.

2. Data gaps to close before publishing listed-only / hotels

  • Enumerate the remaining 94 listed-no-star restaurants (pages 2–4 of the MICHELIN index) and fetch their official detail pages.
  • Verify hotel addresses, distances and nearby-restaurant counts with geocoding.
  • Add Oakland/San Mateo/Marin hotels near Commis, Sun Moon Studio, Wakuriya and Madcap.
  • Confirm exact dollar cost for 2 adults from each restaurant's official menu (MICHELIN does not publish totals).
  • Find official YouTube/TikTok links (none found yet) or confirm absence.
  • Find Instagram for Compis and Madcap San Anselmo.

3. Site implementation suggestions

  • Keep GitHub Pages static HTML (no build step) — already mobile-friendly and fast.
  • Add client-side search/filter (already in app.js) so users can scan tables on phones.
  • Add a "Verified / Unverified" toggle so users can hide unverified rows.
  • Consider adding a map view (restaurants clustered by neighbourhood) once addresses are geocoded.
  • Add a "Last verified" date badge on each page so users know data freshness.

4. Suggested rollout order

  1. Ship starred-restaurant pages + landing + executive summary (this data is complete).
  2. Publish sources/verification page for audit transparency.
  3. Close the listed-only and hotels data gaps (see Q&A page).
  4. Then publish listed-only and hotels as verified.
No manual input rule: All missing data must be found from official sources, not filled in by hand. Leave blanks and flag unverified until confirmed.
