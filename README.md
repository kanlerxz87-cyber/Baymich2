# Baymich2

Bay Area Michelin research: starred restaurants, verification status, and a dashboard.

- **Live dashboard:** `docs/` (served by GitHub Pages). Pages: Dashboard, Michelin Stars, Hotels, Questions, Suggestions, Flagged for Review, Sources.
- **Verification rule:** a value is shown only if it was read from an official source. Blank or "UNVERIFIED" means not confirmed yet. Nothing is inferred.
- **Coordination:** see [COORDINATION.md](COORDINATION.md) for the task board, owners, and logs.
- **Flagged items:** see the Flagged for Review page for source conflicts and data gaps.

Run locally: open `docs/index.html` in a browser (no build step).
